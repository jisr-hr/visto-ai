Merge gate

How it works
  1. On a pull request into a gated branch, Visto AI adds a check to the latest commit. A push does not start a review: the check says it is waiting.
  2. When the pull request is ready, someone comments /done (or re-runs the check). Visto AI reviews it then.
  3. The check fails while a major or blocker finding is still open, and passes once none is. A new commit sets it back to waiting.
  4. For the check to stop merges, make it a required check in the branch's rules on GitHub. Visto AI cannot do that part.
Gated branchesPull requests whose base branch is one of these get the check, for example main. Names must match exactly. Pushes to these pull requests are not reviewed automatically, even when the branch is in Reviewed on every push: they wait for /done. Shadow mode keeps the push reviews.
